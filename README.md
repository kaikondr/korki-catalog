# Каталог «Корки»

Справочники приложения «Корки» (документы моряка): курсы УТЦ (`courses.json`, с `aliases` — всеми известными
названиями), требования к подготовке (`requirements.json`), правила дипломирования по Положению № 378 и памяткам
АМП (`rules.json`), службы капитанов портов (`ports.json`). `manifest.json` — версия, дата и SHA-256 файлов.

Приложение раз в сутки скачивает `manifest.json` с https://kaikondr.github.io/korki-catalog/ и, если версия новее,
файлы каталога; проверяет их и применяет при следующем запуске. Ничего не отправляет.

Файлы собираются скриптами `tools/build_*.py` в репозитории приложения и публикуются `tools/publish_catalog.py`.
Руками не править.
